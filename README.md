# frameworkutil

frameworkutil is a library which allows to provide a basic framework utils required to bring up a framework.

**Usage As a dependency**

```
<dependency>
  <groupId>prj.sunaynatalreja.frameworkutil</groupId>
  <artifactId>frameworkutil</artifactId>
  <version>{latest version}</version>
</dependency>
```

package details can be found on [PackageDetails](https://github.com/sunaynatalreja/frameworkutil/packages/)

Provided Utils
1) extentreportutil - Config to create an extent report util
2) freemarkerreport - - Config to create an extent report util
3) jsonutil - Config to hit get,post,put,delete requests using rest-assured
4) logutil - Config to create log files
5) readdatautil - Read from excel and read from property 
6) webdriverutil - Browser init and handling of both web and mobile element
